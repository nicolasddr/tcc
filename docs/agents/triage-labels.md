# Triage Labels

Os skills falam em termos de cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para as strings de label reais usadas no rastreador de issues deste repositório.

| Papel canônico (mattpocock/skills) | Label neste repo         | Significado                                   |
| ----------------------------------- | ------------------------- | ---------------------------------------------- |
| `needs-triage`                      | `triagem-pendente`        | Precisa ser avaliada                           |
| `needs-info`                        | `info-pendente`           | Aguardando mais informações de quem reportou   |
| `ready-for-agent`                   | `pronto-para-implementar` | Totalmente especificada, pronta para implementação |
| `ready-for-human`                   | `pronto-para-revisão`     | Requer revisão/implementação manual            |
| `wontfix`                           | `sem-correção`            | Não será tratada                               |

Quando um skill mencionar um papel (ex.: "apply the AFK-ready triage label"), use a string de label correspondente desta tabela.

Edite a coluna da direita para refletir qualquer mudança futura de vocabulário.
